# Trees-team15
# Библиотека реализаций деревьев поиска
Библиотека реализует ассоциативный массив с операциями вставки пары элементов ключ-значение, удаления и поиска по ключу с помощью одной из структур данных:

- Красно-черного дерева

- Декартового дерева (Treap)

## Установка
- Склонируйте репозиторий:

```git clone https://github.com/username/trees-project.git```

- Затем перейдите в директорию с проектом:

```cd trees-project```

## Сборка и тестирование
- Собрать библиотеку можно с помощью команды:

```./gradlew build```

## Выполнение тестов:

```./gradlew test```
